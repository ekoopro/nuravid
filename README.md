# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/c0ab4a1d-ea37-433d-a786-6e1e44600099

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env](.env) with your Gemini API key — or simply run the app and open the **Settings** menu (⚙️ icon in the navbar) to paste and save your AI API key from the UI (it is written to `.env` automatically and activates instantly). Get a key at [Google AI Studio](https://aistudio.google.com/apikey).
3. Run the app:
   `npm run dev`
